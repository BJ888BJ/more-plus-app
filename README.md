# MORE+ App

Static single-page demo of **MORE+ — the trusted decision network for women's health**.

- `index.html` — the app (in-memory router: home, shelf, shows, breakthroughs, standard, participate, partner, badge, results)
- `bayer-dashboard.html`, `biotwin-dashboard.html`, `client-x-dashboard.html`, `evidence-editorial.html` — partner demo dashboards opened from the app
- `assets/` — show art, vertical posters, product stills, favicons, wordmark
- `og-image.png` — social preview image

No build step. Deployed on Render as a static site (publish directory `./`). All pages carry `noindex,nofollow` — private demo.

Source of truth for edits is this repo; the Google Drive folder *MORE+ App (Rebuild)* is the pre-git working copy.
